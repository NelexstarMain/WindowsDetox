Windows Detox 0.4.0

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

## Focus Forest looks better
- Real shadows: every tree, bush and decoration casts a shadow computed from the light onto the ground.
- Textured trees, grass and soil, and a soft green colour grade over the whole forest.
- Smooth faces without edge lines, darker bases near the ground, and grass tufts and a turf edge on the board.
- Tiles are roomier: plants and decorations take up less of their tile, so the forest breathes.

## Fixed
- The block screen no longer pops up for Windows' own helpers. Only installed third-party apps are redirected; programs in the Windows folder, inbox Windows packages, Microsoft-signed system images and driver helpers are left alone.
- The block screen closes itself after 8 seconds (not while you are confirming the emergency exit) and shows again for the same app at most every 2 minutes.
- Plugin pages no longer go missing from the sidebar right after launch; they are fetched again while the plugin host is still starting.
