Windows Detox 1.6.0

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

This release merges every development branch into one build: everything from 1.3.0, 1.4.0 and 1.5.0 is now in a single installer.

## Included
- Session setup and app limits from 1.5.0:
  - Session setup and the allowlist are one page.
  - Saved app sets.
  - Per-app scheduled blocks on a weekly grid.
  - Daily, per-day or weekly time pools.
  - Hardened enforcement.
- Focus Forest from 1.3.0 and 1.4.0, now its own plugin: an isometric forest that grows with your focus sessions, with shadows and textures.
- Windows' own components are no longer blocked, and the block screen is quieter: it closes after 8 seconds and shows at most every 2 minutes per app.
- IFEO redirects are kept for third-party programs seen running.
- Plugin pages no longer go missing from the sidebar right after launch.
