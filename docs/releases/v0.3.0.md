Windows Detox 0.3.0

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

## New: Focus Forest (Focus Insights plugin 1.1.0)
- Grow a small isometric forest with your focus sessions. A completed session earns one coin per minute and plants your chosen tree or bush; the longer the session, the bigger it grows (sapling, young, mature, majestic).
- Ending a session early with break-glass leaves a withered plant, which you can clear for a few coins.
- Shop: unlock 10 trees and 4 bushes, and buy 8 decorations (rock, mushrooms, flower bed, bench, stone lantern, pond, well, cabin) to place by clicking a tile.
- Plants are placed automatically; click any object to move it. The field grows from 6x6 to 16x16 as it fills.
- Low-poly models with soft shading, contact shadows and a textured ground; turn the view with the buttons in the corner.
- The Insights page now has Forest and Stats tabs; all statistics are unchanged.

## For plugin authors
- New SDK node `UiScene` draws isometric worlds from flat-shaded low-poly models, with item clicks and the new `UiActionKind.Pick` for empty tiles. Additive API change.

## Fixed
- The UI render job in CI installs ImageMagick itself.
