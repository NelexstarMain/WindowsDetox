Windows Detox 0.2.0

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

## Security and robustness
- Fixed a privilege-escalation path: rollback journal restores now touch only this installation's services, and only with safe DACLs. File ACL and IFEO restores refuse unsafe values. The data folder gets a protected DACL at install and at every service start, which also fixes existing installs.
- Copies of programs placed in writable Windows subfolders (for example `C:\Windows\Tasks`) are no longer treated as system processes.
- Child processes inherit "allowed" status only from their real creator, not from a parent they claim.
- During a session, running processes are re-checked every 5 seconds, so a missed start event no longer means a permanent bypass. The process monitor restarts by itself if it stops.
- Process start times come from the system, so blocking keeps working through the repeated hour at the end of daylight saving time.
- A failed system restore at the end of a session is retried in the background instead of waiting for a service restart.
- The installer and uninstaller stop on any service error before deleting files or data.
- New audit: `docs/audits/2026-11-mechanics-audit.md`.

## New look
- A refined dark palette with clearer surface elevation; the lime accent is unchanged.
- A unified button system with consistent sizes and states. Primary buttons are lime, and warnings use a warm orange (#E8914A).
- "Emergency exit" is a calm orange outlined pill.
- A minimalist monochrome sidebar.
- Every page has a consistent title and subtitle header, and the session timer sits on its own card.
- Goals & Tasks has checkbox task rows with struck-through done items, an inline "Add a task" field and a better empty state.
- Calendar event blocks fill their column with an even 2 px inset, and short blocks keep their start time.
- Allowlist: the Domains column has the same header as Apps. Session setup uses sentence-case section titles, and disabled plugins are dimmed.
- Dashboard widgets line up with an even bottom edge.
