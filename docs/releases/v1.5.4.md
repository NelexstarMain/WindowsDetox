Windows Detox 1.5.4

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

## New
- The block screen is now a small card in the bottom-right corner:
  - It never takes focus and closes by itself after 5 seconds.
  - It stays while the pointer is over it.
  - Click it for the reason, session clock, emergency exit and plugin content.
- Settings has a new "Block notice" switch. Turn it off and blocked apps close with nothing shown on screen. Blocking itself is unchanged.

## Fixes
- Console programs no longer fail to start because the Windows Terminal console host (OpenConsole.exe) was closed.
- A blocked app that keeps restarting no longer brings the notice back every few seconds.
- Plugins have more time to load on a cold start, and larger plugin pages are allowed.
- Plugin pages are loaded again after launch even when some are already shown.
