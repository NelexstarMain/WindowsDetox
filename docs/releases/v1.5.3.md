Windows Detox 1.5.3

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

## Fixed
- An allowed console program could be closed during a session. The session closed Windows Terminal's console host (OpenConsole.exe), which took down a console program that had just started with it. The console host is now never closed, but only the copy in the installed Windows Terminal package counts. Windows Terminal itself is still blocked during a session.
- Fixed a timing-sensitive supervisor test.
