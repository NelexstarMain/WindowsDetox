Windows Detox 1.2.1

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

## Fixed
- Sessions no longer fail with "could not be enforced and was rolled back: Attempted to perform an unauthorized operation." If Windows or security software refuses one extra protection (an app's IFEO redirect, a folder deny ACE or a service DACL), that item is skipped and the session starts with a warning naming it. The process monitor still stops those apps. The browser proxy policy stays required.
- Allowlisted apps started during a session are no longer killed. The Windows process-start event carries no image name on current Windows, so the service now resolves the path from the process ID. A process it cannot identify is left alone and checked again 5 seconds later.
- When a session cannot start, the message names the failing step, the target and the error type.
- Mouse-wheel scrolling works with the pointer over cards, lists and fields on every page. Inner scroll areas such as the calendar's hour grid scroll first and hand over at their edges.
- Plugins page: compact Disable/Enable/Remove buttons, and header actions that wrap on narrow windows.

## Testing
- CI now installs the app on Windows and runs a full session end to end: IFEO, ACLs, service DACL, proxy, killing and allowing processes, a write-protected IFEO key, and a complete rollback. A new installer is published only if every check passes.
