Windows Detox 0.5.0

Unsigned installer: Windows SmartScreen may warn (More info, Run anyway). Try it in a VM first.

## Session setup in one place
- The allowlist and session setup are one page. Switch between Apps and Websites, pick a duration and start.
- Smaller app tiles with icons tinted to the theme's gray-green; selected apps light up.
- Saved app sets: save the current selection under a name and apply it later with one click.

## App limits (new)
- Rules for single apps that apply outside sessions:
  - Scheduled block: draw blocked hours on a weekly grid (the same grid as the Calendar plugin). Presets for work hours and evenings.
  - Time pool: a limit every day, a separate limit for each day, or one limit per week. Only foreground time while you are active counts.
- Order: a running session decides first, then the scheduled block, then the time pool.
- A rule cannot be loosened while its app is blocked. The time zone is frozen when rules are saved.
- Blocked apps are closed and the block screen explains why.

## Security and robustness
- Only the registered agent may report the foreground window; the service resolves image paths itself.
- Rules on Windows system binaries are refused; the UAC and credential prompts are never closed.
- File hashing is bounded in size and time, and network or device paths are never opened.
- The service starts even if a rules file cannot be read; a clock jump cannot lock a time pool.
- Fixed a timing-sensitive supervisor test.

## IPC contracts (additive)
- `appSets.get/set`, `appRules.get/set/status` and their DTOs.
